## ⭐ NEW [3강] 장세 파악 및 종목 선정 실전편

### 4. 시장을 읽은뒤 주도섹터 찾는법
> 돈은 어디로 몰리고 있는가?
```
- 종목보다 먼저 섹터를 본다.
  - **왜 이 섹터로 돈이 몰리는가를 확인**
  - 실적, 재료 등등 이유를 명확인 알아야 한다.
- **주도섹터는 하루에도 여러번 바뀔수 있다.** 
  - 그래서, 하루종일 거래대금 상위종목을 확인
  - 종목명만 보더라도 어떤 섹터인지 알아야 장중에 주도섹터를 바로 알수 있다.
```

- **시장의 돈이 어디로** 몰리고 있는가 이걸 확인하려면..
  - **실시간종목조회순위[0198]** 를 본다
  - **여러 섹터가 많이** 보인다 = **분산 장세**
  - **특정 섹터가 군집을 형성** 해 있다 = **주도주 장세**
- 장세가 계속 가는지, 몇분 혹은 몇시간 뒤에 바뀌는지 정해져 있지 않다. 
  - **주식은 뭐죠? 생물이죠** 
  - [0198]화면에서 종목명을 보더라도 섹터로 보인다. 반도체,반도체,원전,로봇,광통신,소부장...
  - 특징주를 계속보다보면 어떤 종목이 무슨섹터인지, 대장종목인지, 후속종목인지 알 수 있다.
- 아침에 봐야할 것!!!
  - [x] 전일강세주
    - **전일 강세주가 다음날에도 강할 가능성 유무를** 다음날에도 강하다면 적극적으로 매매해볼수 있다.
    - **전날의 고가를 돌파할때** 혹은 전날의 고가 위에 주가가 형성할 때 매매를 많이 한다.
    - **심리가 좋은 구간.** 전날에 매수한 사람들 다 수익인 구간. 
    - 당일 최고점에서 진입하지만 않으면 누구나 다 수익인 구간. 
    - 이런 일봉의 흐름, 분봉의 흐름에서 더 간다.
    - 심리가 좋다.
    - 수익중인 사람들도 홀딩. 더 길게 보려고 익절하려는 사람들도 분할로 매도한다.
    - 보유중이지 않은 사람들은 주가가 계속 올라가니까 매수하고 싶어진다.
    - 매수세가 매도세를 이기면서 체결이 되면서 주가가 올라간다. 
  - **대체거래소** (7:40~8:00am)
    - [x] 1. 전일 강세주 체크
    - [x] 2. 당일 새롭게 올라오는 종목 체크 (10% 길목구간) 
      - NXT장에서는 10%나 15%에서 밀리는 경우도 많으므로, 관망
      - **수급이 몰릴때만 매매. 즉, 1종목만 길목구간에 들어왔을때**
  - **정규장** (8:50~9:00am)
    - [x] 1. 전일 강세주 체크 (정규장에서 시작하는 종목)
    - [x] 2. 당일 대체거래소 강세주 체크
    - [x] 3. 당일 새롭게 올라오는 종목 체크 (10% 길목구간)
      - 보통 10%~15%가 저항대 
      - 올라가는 종목이 더 잘가고, 내려가는 종목은 10개중에 1~2개만 반등
      - 올라가는 종목은 손절만 잘하면 수익내기 쉽다. 눌림은 대형주에서만!
- **당일 새롭게 올라오는 종목 체크 (10% 길목구간)**
  - 당일 새롭게 올라오는 강세주는 어떻게 체크할까여?
    - **실시간종목조회순위[0198]**
  - **분산장세** = 주도주인척 올라가다가 픽 쓰러진다.
    - 2%든 3%든 5%든 줄때먹고 나와라 = 분산장세
  - **주도주장세** = 10% 길목구간에 잘만 진입하면 20%~25%까지 간다. 
    - 억대트레이더들이 가장 좋아하는 매매. 그들이 불타가를 선호한다.
    - 10%든 15%든 18%든 25%까지 간다는걸 알고 있는거다.
    - 위로 올라갈때마다 확인하고 불타기를 한다.
    - 10종목 매매해서 5종목 손실나고 5종목 수익나더라도 월별 억대 수익이 찍히는 이유가
    - 손절은 짧게, 수익은 길게 끌고간다. 
    - 다만, 주도주 매매가 한달에 5회 미만으로 나온다. 
      - 그렇기 때문에 억대 트레이더 아닌이상 회전율 적으로 손해다.
- 저를 예시로 들어보자면 시소타기 장세에서도 스캘핑이니 돌파매매
  - 단점이 뭐냐면 줄때먹는 전략에 익숙해셔 3~5% 수익 찍히다 냅다 매도하는 습관이 생긴다.
    - 주도주 장세에게 길게 먹질 못한다.
    - 한달에 주도주 장세는 5일 이하로 나온다. 대부분 시소타기 장세이다.
    - 평소에 줄때 안먹었더니 다시 내려온다 이걸 계속 경험하다보면 아 그래 그냥 줄때먹고 나오자. 이렇게 된다.
    - 3% 먹고 나오자 이게 어디냐
    - 수익냈으니 마감하자
    - 3% 먹고 수익지키고 마감
  - 뱁새가 황새 따라가다 가랭이 찢어진다.
    - 황새는 억대트레이더들, 100억 200억 버는 트레이더.
    - **황새가 되려고 자기 그릇에 맞지 않는 행동으로 이어진다면 결국 그 그릇은 깨진다.**
  - 행새가 되는 사람들은 결국에는 100억 200억 벌려면 어떻게 해야겠어요
    - 종목압축? 좋은타점? 시장? 이런것도 중요하지만
    - **가장 중요한게 비중배팅**
    - 몇억 몇십업 몇백억 배팅으로 가는 과정. 
    - 이안에 10,000명중에 9,999명은 그릇이 깨집니다.
    - 깡통찬다는 뜻이다.
    - 굳이 뱁새가 황새가 되려고 할 필요가 있을까?
    - 하루에 100~200 수익만으로 만족하자. 
    - 이걸 **수익 지키고 마감하고 큰 손절만 나가지 않는다면** 한달에 2000~3000은 충분히 가능하다.
    - 이 결론이 나온거다. 다만 이렇게 하면 억대트레이더가 되는건 불가능
    - 밖에 나가면 상위 1%이다. 대기업 임원급이다. 
- 눌림매매를 왜 대형주 삼성전자, SK하이닉스에서만 할까?
  - 삼성전자, SK하이닉스가 시장 주도주이기 때문이다.
  - 시장 주도주는 무슨말이냐면 시장을 이끌고 가는 주식
  - 시장의 평균보다 강하다는 것이다. 
- **개별주에서 떨어진다고 물타기하다보면, 계좌가 박살난다!!**
  - 결국 물타기의 끝은 미수몰빵으로 끝이 난다.  
  - 근데 미수몰빵으로 물타기 했는데, 한번 더 떨어지면 거기서 깡통 차는것이다.
- 시장이 무너졌을때 개별주 매매하자 이런적은 거의 없다.
  - 아마 한번도 없을것이다.
  - 삼성전자, SK하이닉스, 삼성전기, SK스퀘어 이런 종목은 **시장주도주**
  - LG전자 이런건 **당일주도주** = 젠슨황 방한으로 올라갔다가, 재료가 소멸되면 저점이라도 반등은 10%미만 !

### 5. 종목 압축하는 방법
> 여러 종목 중 가장 강한 종목 찾기
```
- 주도섹터가 있다면, 그중에서 **가장 강한 거래대금과 상승률로 한두종목만** 본다.
- 외국인과 기관의 매매, 뉴스, 차트를 확인
- 너무 많은 종목을 등록해놓고 보지만, 매매하는 종목은 몇개 되지 않는다.
```

### 장전 준비

- 대체거래소 장전
  - [x] 미증시 흐름
  - [x] 전일 강세주
  - [x] 당일 새로운 강세주
- 정규장 장전
  - [x] 전일 강세주
  - [x] 대첵래소 강세주
  - [x] 당일 새로운 강세주


- **미 증시 흐름부터 체크** 한다. 
  - 예를들어서 메타 +6% 왜 올라갔는지 이유를 찾아본다.
    - 네이버에 메타 뉴스 들어가거나 주식창에서 메타 뉴스 들어가서 찾아본다.
    - 올라간 원인을 찾고, 한국주식에서 연결이 되는지.
  - 예를들어서 마이크론 +10% 상승
    - 올라갔는지 이유를 찾고, 실적관련해서 올라갔네?
    - 국내주식 같은 메메로 반도체인 SK하이닉스, 삼성전자도 실직이 잘나오고 있고, 시장점유율도 좋고, 한국주 대장주니깐 얘네들도 키맞추기로 올라갈수 있겠다.
    - 마이크론이 10% 상승했는데, 삼전닉스도 충분히 10% 상승해줄수 있겠다.
    - 삼전닉스가 3~5% 상승하고 시작한다. 그러면 위로 5% 더 올라갈 여력이 남았네.
    - 삼전닉스가 8~9% 상승했다. 그러면 더 먹을구간이 없겠네 판단하고 낙폭과대 기다리거나, 다른섹터 다른종목 시소타기 흐름을 체크 
- 시장이 분산장인지 주도주장세인지 파악하는 법은
  - **실시간종목조회순위[0198]** 로 파악
    - [0198]에 반도체가 많이 보인다. 그러면 반도체 주도주 장세일 가능성이 높다.
    - 그러면 반도체 섹터에서 1등부터 대장주 후발주 체크
  - **등락률상위[0181], 상한가/하한가[0162]** 로 체크  => 상한, 상승
    - 등락률순위로 보면서 뉴스도 체크
    - 특징주가 있으면 확인
    - 평소 주도주나 후속주이면 강세종목에 올린다.
    - 모르는 종목이면 스킵, 평소 주도주였던적이 없음!
  - 위를 동시에 체크하고 매매할게 없으면 관망한다. 
    - 평소 **종목만 보더라도, 어떤 섹터인지 알아야 한다.**
  - 강세종목에 등록
    - 어떤 종목이 빠지면 다른게 올라간다.
    - **관심종목 강세종목 내에서 돈의 흐름이 보인다.**

### 6. 마지막에 타점을 적용하는 이유
> **시장 ⇒ 섹터 ⇒ 종목 ⇒ 타점**
```
- 대부분 타점부터 공부한다.
- 타점은 기술인데, 기술은 언제든지 공부할 수 있다.
- **먼저 시장을 보고, 주도 섹터를 보고, 대장종목을 찾고, 차트에서 타점을 확인한다.**
- 시장이 좋으면 타점도 잡기 쉽고, 시장이 안좋으면 타점잡기도 어렵다.
```
