# S5. 시크릿 강의 (1) 계좌관리
> 초보 vs 중수 vs 고수

```
더트레이딩 F존 << 특허
트레이더김씨 K눌림 피보나치 << 특허X

O강 일부분을 녹화해서 다른사람한테 판매한다 << 불법
O강 듣고 느낀점 얘기할때 이렇게 매매하더라 <<괜찮다는거지
```

### 중수와 고수의 차이
> 기법, 심법, 비중관리(계좌관리)

- 중수와 고수의 차이
  - 중수 : 예수금 많아봐야 1~2억
  - 고수 : 예수금 10억 이상
- 주식 5년이상
  - 기법은 똑같이 안다
  - 비중베팅의 차이

### 초보에도 2단계가 있다

- 기법도 모르는 초보 vs 기법은 아는 초보
  - 시간 절약을 위애 강의를 듣는게 좋다
  - 기법을 아는 초보는 굳이 강의 들어야 하나 싶다
- 실력을 키우고 싶은지, 수익을 키우고 싶은지 일단 이걸 먼저 선택해라
  - 실력을 키우고 싶은사람
    - 계좌 100만원 세팅, 어차피 시장에서 다 뺏어간다
  - 수익을 키우고 싶은사람
    - 계좌 1000만원 세팅, 계좌관리하는방법, 비중조절하는 방법 이것을 습관화 해야한다
    - 예수금의 10%

```js
  100만원 세팅해서 예수금의 100%씩 들어가는 사람들
  잃잖아요? 한방 복구 심리 발동
  미수몰빵 100만원으로 하다가 8만원 잃었어 92만원 << 운에 맡긴다
  300만원 3%만 벌자
  그러다 -3% 되면 -9만원, -10만원 됐을때 x같다.

  1억에서 
  2000으로 20% 비중 조절
  500~1000 시가매매든 돌파매매든 신규주매매든
```

### 실력을 키우고 싶다면
> 100만원 세팅
  
- 100만원 다 날린다는 마인드로 매매
  -그러면 매매가 잘된다.
  - 미모사의 목숨학 개론
- 다한다
  - 스캘핑, 돌파, 주도주눌림, 상따, 시가매매, 종가매매 
  - 100만원 예수금의 50~100% 쓰는거거든요
  - 성공하면 억대트레이더, 실패하면 깡통
- 성공한 사람이 5000명 중에 5~10명 될까
- 극소수 0.1%~0.2%만이 가능

### 계좌를 불리고 싶다면 
> 1000만원 세팅

- 예수금의 10%씩 들어간다
- 3종목 이상 매수 금지 ⇒ **종목압축** 을 하지말라고해도 하게된다
- 100만원씩 A, B, C
  - 어떤 매매를 해도 좋다
    - 대신에 하지말아야 할 매매
    - 스캘핑, 상따, 돌파 ⇒ 빠른매매 금지
- 기본 전제가 심리가 우선
  - 계좌를 1000만원을 
    - 수익나도 천천히... 100% 100.1% 100.5% 101% 
    - 내려가도 천천히... 100% 99.5% 99% 98.7%
    - 월 5~10% 버는 매매
  - 수익나고 실력이 생기면 3000~5000 세팅해서 한다
    - 월 5~10% 버는 매매
  - 5000명중에 250~500명 정도는 가능한 매매
