## ⭐ NEW [1강] 시장을 먼저 읽는 트레이딩

### 1. 상승장, 횡보장, 하락장 구분하는 법
> 현재 시장은 어떤 시장인가?

- 앞전고가의 위에서 흐르면 상승시장
- 올라가더라도 저항대를 만들면서 올라간다
- 상승장이 끝나려면, 앞전 저항대를 이탈하면 상승세가 끝났다고 판단
- 고가의 선을 긋고, 지지받고 올라가는지 이탈하는지를 보고 판단
- 피보나치선 확인, 올라갈때 지지받는 선을 확인
- 상승추세가 강할때 236과 382는 잘 닿는데, 중심선까지는 잘 닿지 않는다.

### 2. 투자심리가 살아있는 시장 vs 꺽인 시장
> 돈이 계속 들어오는 시장인가?


### 3. 주도주 장세 vs 시소타기 장세
> 지금 적극적으로 매매해야 하는 시장인가?

- 주도주 장세에서는 수익을 극대화
- 시소타기 장세에서는 손실을 최소화

### 4. 시장을 읽은뒤 주도섹터 찾는법
> 돈은 어디로 몰리고 있는가?

- 종목보다 먼저 섹터를 본다.
- 왜 이 섹터로 돈이 몰리는가를 확인
- 실적, 재료 등등 이유를 명확인 알아야 한다.
- 주도섹터는 하루에도 여러번 바뀐다. 그래서, 하루종일 거래대금 상위종목을 확인
- 종목명만 보더라도 어떤 섹터인지 알아야 장중에 주도섹터를 바로 알수 있다.


### 5. 종목 압축하는 방법
> 여러 종목 중 가장 강한 종목 찾기

- 주도섹터가 있다면, 그중에서 가장 강한 거래대금과 상승률로 한두종목만 본다.
- 외국인과 기관의 매매, 뉴스, 차트를 확인
- 너무 많은 종목을 등록해놓고 보지만, 매매하는 종목은 몇개 되지 않는다.

### 6. 마지막에 타점을 적용하는 이유
> 시장 -> 섹터 -> 종목 -> 타점

- 대부분 타점부터 공부한다.
- 타점은 기술인데, 기술은 언제든지 공부할 수 있다.
- 시장이 좋은 타점도 잡기 쉽고, 시장이 안좋으면 타점잡기도 어렵다.
