# 종가베팅

1. 100%는 아니다. 다만 조금더 승률을 높이는 방법
  - 오늘 상승한 섹터가 내일도 상승할 확률이 높다
2. 일정을 체크하라 
  - 이번주 일정
3. 돌파자리에 파킹한 종목이 좋다
  - 돌파자리에 종가형성한 종목
4. 최근에 강한 거래대금 / 장대양봉 / 눌림 / 이후 박스돌파 -> 돌파한 자리 (3번의 응용버전)
  - 최근 거래대금 + 장대양봉
5. 상단 매물대가 없는 신고가 자리 
  - 리스크 : 많이 빠질수 있다
6. 장막판에 수급이 붙는 종목들
  
### 종목선정

No   | 종가베팅 승률 올리는 6가지 확인 사항
:---:|-----
❶ | 오늘 강한 섹터는 내일도 강하다
❷ | 일정을 체크할 것
❸ | 돌파자리에 종가를 형성했나?
❹ | 최근 강한 거래대금을 동반한 장대양봉/눌림 등
❺ | 신고가 자리
❻ | 장 막판에 수급이 붙는 종목들
★ | ✓ 위 조건중 3가지만 겹처도 승률은 UP
┗  | ✓ 강했던 섹터 ∩ 이번주 일정

- 오늘 상승한 섹터가 내일도 상승할 확률이 높다
- 오늘 그럼 어떤 섹터?
- 핀테(가상자산) 오전에 강했음
- 원전, 조선, 방산 오후에 수급 
- TIP1. 지수, 종목이 음봉 떨어지는 날 공략을 한다.
  - [x] 지수 반등 종목 저가매수세 유입
  - [x] 조건 : 시장을 주도하는 섹터 안에 있는 종목에서 선별해야 한다.
- TIP2. 지수가 조정받는 날
  - [x] 돌파자리에 있는 종목을 매매하라
  - [x] 지수가 안좋음에도 수급이 들어옴
